# Clarify

Use this when the request is broad, ambiguous, or missing a definition of done.

## Method

1. Inspect available repository evidence before asking about facts Codex can discover.
2. Identify the single uncertainty with the largest effect on scope, risk, or acceptance.
3. Ask one concise question at a time.
4. Stop as soon as the request is safe to plan or execute.
5. If the user declines clarification, state the assumptions and hand off.

## Output

- outcome
- constraints and non-goals
- decision boundaries
- acceptance criteria
- unresolved assumptions
- lightest suitable next skill
