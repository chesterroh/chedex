# Best-Practice Research

Use when current external guidance materially affects a technical decision.

## Method

1. Inspect the repository to identify the actual version, constraints, and current pattern.
2. Prefer official documentation, standards, specifications, release notes, and original research.
3. Use secondary sources only to fill a clearly identified gap.
4. Separate upstream facts, repository facts, and recommendations.
5. Check dates and versions; do not present stale guidance as current.
6. Compare viable options against the project's real constraints.
7. Remain read-only unless the user separately requests implementation.

## Output

- recommendation and applicability boundary
- repository evidence
- primary-source links near supported claims
- alternatives and tradeoffs
- confidence and unresolved uncertainty
